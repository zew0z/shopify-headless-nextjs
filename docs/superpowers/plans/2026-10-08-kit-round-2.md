# Kit Round 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the gaps the second rehearsal left open, so a fresh agent wiring a received frontend writes no list, filter, menu or cart plumbing of its own and cannot pass `frontend-check` with the shop name or store claims typed into pages.

**Architecture:** One new audit module (`scripts/frontend/claims.mjs`) finds typed claims, the shop name, typed metadata and stock photos in pages and components; the audit reports them and the check fails on them. One new browser-safe SDK module (`src/lib/shopify/listing.ts`) holds sorting and URL-filter plumbing; `index.ts` gains `getAllProductsPage` and `getListPage`, and list reads can ask for fewer variants and images. Small helpers land where their neighbours live (`productOptions` in `variants.ts`, `footerColumns` in `menu.ts`, cart line extras in `cart-store.ts`). The rest is precision fixes to the audit, CLI and kit-install, the wiring guide, and a third rehearsal as the gate.

**Tech Stack:** TypeScript SDK (Next.js 16.3.4, React 19.2.8), Node ESM `.mjs` tooling, `node --test`, no new dependencies.

**Spec:** `docs/superpowers/plans/2026-10-07-kit-round-2-backlog.md` (items cited as `B<n>`, deferred minors as `M<n>` in the order listed there) and the second rehearsal log, copied into this repo in Task 0 as `docs/superpowers/rehearsals/2026-10-07-log-2.md` (entries cited as `L2.<n>`).

## Global Constraints

- No new npm dependencies. Tests use `node:test`; run with `pnpm test:scripts`.
- Nothing hardcoded (memory `nothing-hardcoded`): every product, price, currency, image, menu link, policy and store claim comes from Shopify. When Shopify cannot supply it, the frontend hides it and the agent lists it for the owner.
- Every new or changed GraphQL document is an exported `const ...Query` string in `src/lib/shopify/queries.ts`, and `pnpm shop-setup validate-queries` must report all documents valid against both `2026-07` and `2026-10` (`pnpm shop-setup validate-queries --version=2026-10`).
- Catalogue and content reads throw on failure (`ShopifyError`). They never return a made-up or empty answer in place of an error.
- Browser-safe SDK files (`cart-client.ts`, `cart-store.ts`, `cart-provider.tsx`, `variants.ts`, `menu.ts`, `money.ts`, and new `listing.ts`) import nothing server-only (no `client.ts`, `config.ts`, `index.ts`); `scripts/shopify/client-boundary.test.mjs` enforces it.
- Plain words in every message a human reads.
- Existing exported function names, parameters and return types stay compatible (received frontends may already use them). New behaviour arrives as new functions or new optional fields.
- `pnpm build` and `pnpm lint` pass in the kit repo after every task that touches `src/`.
- Nothing is "verified" until it ran against mock.shop in the rehearsal (Task 14), and against a development store later. Say "unverified" otherwise.
- The owner's shell is fish: wrap loops and multi-line commands in `bash -c '...'`.
- Work on branch `kit-round-2`; Task 14 merges it to `main` and pushes the same day.

## Decisions made while planning (read before Task 6)

- **All-products filters (B2).** Checked on 2026-10-08: mock.shop answers `search(query: "")` and `search(query: "*")` with zero products and no filters, so search cannot stand in for "all products" there, and it is unknown on a real store. `getAllProductsPage` therefore reads a collection with handle `all` when the shop has one (an automated collection the owner creates; collections get Shopify's filters) and falls back to `getProductsPage` with no filters when it does not. Whether Shopify accepts the handle `all` for a new collection is **unverified**; `allHandle` lets the guide name another.
- **Cart compare-at (B7).** Shopify gives a line's compare-at price per item (`compareAtAmountPerQuantity`) and no compare-at total. `CartLineView` gets `compareAtUnitPrice` (Shopify's number), not a total the browser multiplies out.
- **Light list reads (B5).** `productFragment` takes `$variantCount` (default 50) and `$imageCount` (default 10). List reads accept `variants` and `images`. Nothing changes for callers that pass neither.
- **Filters in the URL (B3).** Repeated `filter=<Shopify's value.input JSON>` parameters plus `price.min` / `price.max`. A plain GET `<form>` produces exactly this, so the filter form needs no client JavaScript.

```js
import { existsSync, readFileSync } from "node:fs";
import path from "node:path";

const read = (dir, file) => readFileSync(path.join(dir, file), "utf8");
const COMMENT = /^\s*(\/\/|\/\*|\*)/;
const TEST_FILE = /(^|\/)(__tests__|e2e[^/]*|tests?)\/|\.(test|spec)\.[jt]sx?$/;
const ROOT_LAYOUT = /^(src\/)?app\/layout\.[jt]sx?$/;
const HOME_PAGE = /^(src\/)?app\/page\.[jt]sx?$/;
const PAGE_OR_COMPONENT = /^(src\/)?(app|components)\//;

/** Words that make a promise about the shop. Each is the owner's to make, in Shopify, not the frontend's. */
const CLAIMS = [
  /\bfree (shipping|delivery|returns?|exchanges?)\b/i,
  /\b(returns?|refunds?|exchanges?|warranty|guarantee)\b.*\b\d+[- ]?(days?|weeks?|months?|years?)\b/i,
  /\b\d+[- ]?(days?|weeks?|months?|years?)\b.*\b(returns?|refunds?|exchanges?|warranty|guarantee)\b/i,
  /\b(taxes|tax|vat)\s+(included|incl\.?|inclusive)\b|\bincl\.?\s+(vat|tax)\b/i,
  /\b([Hh]and)?[Mm]ade in [A-Z]/,
  /\b\d(\.\d)?\s*(\/\s*5\s*)?(stars?|★)|★{3,}/i,
  /\b\d[\d,.]*\+?\s+(reviews|ratings|happy customers|customers)\b/i,
  /\bnewsletter\b/i,
  /©\s*(\d{4}|[A-Za-z])/,
  /\b(since|est\.?|established)\s+\d{4}\b/i,
  /\bmoney[- ]back\b|\b(secure|safe) (checkout|payments?)\b/i,
  /\b(ships?|dispatched|delivered) (in|within|every) \d/i,
  /\bevery \d+ (days?|weeks?|months?)\b|\bcancel any ?time\b/i,
];
const STOCK_PHOTO = /\b(images\.unsplash\.com|source\.unsplash\.com|plus\.unsplash\.com|images\.pexels\.com|picsum\.photos|placehold\.co|placehold\.it|via\.placeholder\.com|placekitten\.com|loremflickr\.com|i\.pravatar\.cc|randomuser\.me|dummyimage\.com|fakeimg\.pl)\b/;
// String values of these attributes are code, not words a shopper reads.
const CODE_ATTRIBUTE = /\b(className|class|id|htmlFor|key|href|src|type|rel|target|role|name|style|as|variant|size|color|method|action|data-[\w-]+)\s*=\s*\{?\s*$/;
const STRING = /"(?:[^"\\\n]|\\.)*"|'(?:[^'\\\n]|\\.)*'|`(?:[^`\\]|\\.)*`/g;

const stripExpressions = (line) => {
  let text = line;
  for (let prev; prev !== text; ) {
    prev = text;
    text = text.replace(/\{[^{}]*\}/g, " ");
  }
  return text;
};

const clean = (text) => text.replace(/&amp;/g, "&").replace(/\s+/g, " ").trim();
// Text outside the tags on a line is shown only when it has no code in it ("Lumen <span>&</span> Loom" is all text).
const outside = (text) => (/[=();:{}<>]/.test(text) ? "" : text);

/**
 * Words a shopper reads on a JSX line: the text between tags, plus text before the first or after the last
 * tag when it is not code, with {expressions} removed. A line with no tags counts only when it is plain words.
 */
export function visibleText(line) {
  if (COMMENT.test(line) || /^\s*(import|export\s+\*|export\s+\{)/.test(line)) return "";
  const text = stripExpressions(line);
  if (!/[<>]/.test(text)) return /[=();:{}]/.test(text) || /^\s*[a-z_$][\w$]*,?\s*$/.test(text) ? "" : clean(text);
  const first = text.indexOf("<");
  const last = text.lastIndexOf(">");
  const pieces = [];
  if (first > 0) pieces.push(outside(text.slice(0, first)));
  for (const m of text.matchAll(/>([^<>]*)</g)) pieces.push(m[1]);
  if (last >= 0 && last < text.length - 1) pieces.push(outside(text.slice(last + 1)));
  return clean(pieces.join(" "));
}

/** String literals a shopper may read (alt text, placeholders, props), minus code attributes and imports. */
function readableStrings(line) {
  if (COMMENT.test(line) || /^\s*(import|export\s+\*|export\s+\{)|^\s*["']use (client|server)["']/.test(line)) return [];
  const out = [];
  for (const m of line.matchAll(STRING)) {
    if (CODE_ATTRIBUTE.test(line.slice(0, m.index))) continue;
    const inner = m[0].slice(1, -1).replace(/\$\{[^{}]*\}/g, " ").trim();
    if (inner) out.push(inner);
  }
  return out;
}

const shorten = (text) => (text.length > 60 ? `${text.slice(0, 57)}...` : text);

/** The shop's name as the received frontend typed it: a literal title in the root layout, or `name` in its site data. */
export function findBrand(dir, files) {
  for (const file of files.filter((f) => ROOT_LAYOUT.test(f))) {
    const lines = read(dir, file).split("\n");
    for (let i = 0; i < lines.length; i++) {
      const m = /\b(?:title|default)\s*:\s*(["'`])([^"'`$]+)\1/.exec(lines[i]);
      const name = m?.[2].replace(/%s/g, "").split(/\s+[|·•—–-]\s+/).map((s) => s.trim()).find((s) => s.length >= 3);
      if (name) return { name, file, line: i + 1 };
    }
  }
  const siteFiles = files.filter((f) => /(^|\/)(site|site-?config|config)\.[jt]sx?$/i.test(f) || /(^|\/)(data|content|constants|config)\/site/i.test(f));
  for (const file of siteFiles) {
    const lines = read(dir, file).split("\n");
    for (let i = 0; i < lines.length; i++) {
      const m = /^\s*(?:name|siteName|storeName|shopName|brand)\s*:\s*(["'`])([^"'`$]{3,})\1/.exec(lines[i]);
      if (m) return { name: m[2].trim(), file, line: i + 1 };
    }
  }
  return null;
}

/** Lines of the root layout's `export const metadata = {...}` object, as [lineIndex, text]. */
function metadataLines(lines) {
  const start = lines.findIndex((l) => /export\s+const\s+metadata\b/.test(l));
  if (start === -1) return [];
  const out = [];
  let depth = 0;
  for (let i = start; i < lines.length; i++) {
    out.push([i, lines[i]]);
    depth += (lines[i].match(/\{/g) ?? []).length - (lines[i].match(/\}/g) ?? []).length;
    if (depth <= 0 && i > start) break;
  }
  return out;
}

/**
 * Words and pictures typed into pages and components that should come from Shopify:
 * store claims, the shop's name, the root layout's metadata, the home headline and stock photos.
 */
export function findTypedClaims(dir, files, { skip = [] } = {}) {
  const brand = findBrand(dir, files);
  const scanned = files.filter((f) => !skip.includes(f) && !TEST_FILE.test(f) && (/\.[jt]sx$/.test(f) || (PAGE_OR_COMPONENT.test(f) && /\.[cm]?[jt]s$/.test(f))));
  const found = [];
  const seen = new Set();
  const add = (file, line, kind, what) => {
    const key = `${file}:${line}:${kind}`;
    if (seen.has(key)) return;
    seen.add(key);
    found.push({ file, line, kind, what: shorten(what) });
  };

  const config = ["next.config.ts", "next.config.mjs", "next.config.js", "next.config.cjs"].find((f) => existsSync(path.join(dir, f)));
  if (config) read(dir, config).split("\n").forEach((text, i) => {
    const m = !COMMENT.test(text) && STOCK_PHOTO.exec(text);
    if (m) add(config, i + 1, "stock photo", m[1]);
  });

  for (const file of scanned) {
    const lines = read(dir, file).split("\n");
    const jsx = /\.[jt]sx$/.test(file);
    if (ROOT_LAYOUT.test(file)) {
      for (const [i, text] of metadataLines(lines)) {
        const m = /^\s*(title|default|description)\s*:\s*(["'`])([^"'`]*)\2/.exec(text);
        if (m && !m[3].includes("${") && m[3].trim()) add(file, i + 1, "metadata", `${m[1]}: ${m[3]}`);
      }
    }
    lines.forEach((line, i) => {
      if (COMMENT.test(line)) return;
      const photo = STOCK_PHOTO.exec(line);
      if (photo) add(file, i + 1, "stock photo", photo[1]);
      const texts = [...(jsx ? [visibleText(line)] : []), ...readableStrings(line)].filter(Boolean);
      for (const text of texts) {
        if (CLAIMS.some((c) => c.test(text))) add(file, i + 1, "claim", text);
        if (brand && file !== brand.file && text.includes(brand.name)) add(file, i + 1, "shop name", brand.name);
      }
      if (HOME_PAGE.test(file)) {
        for (const m of stripExpressions(line).matchAll(/<h1\b[^>]*>([^<]*)/g)) {
          const words = m[1].trim().split(/\s+/).filter(Boolean);
          if (words.length >= 2) add(file, i + 1, "headline", words.join(" "));
        }
      }
    });
  }
  return found.sort((a, b) => a.file.localeCompare(b.file) || a.line - b.line);
}
```

/**
 * Sorting and filtering product lists through the URL, the same way for a collection,
 * all products and search results. Safe in client components: imports only types.
 */
import type { CollectionSortKey, Filter, ProductFilterInput, ProductSortKey, SearchSortKey } from "./types";

/** The sort a shopper picks. Each read turns it into its own Shopify sort key. */
export type SortChoice = "featured" | "relevance" | "best-selling" | "newest" | "price-asc" | "price-desc" | "title-asc" | "title-desc";
/** Which read serves a list. */
export type ListScope = "collection" | "all" | "search";

export interface ListOptions {
  /** A SortChoice from the URL. Anything else is ignored and the read's default applies. */
  sort?: string;
  filters?: ProductFilterInput[];
  cursor?: string;
  limit?: number;
  /** How many variants and images each product carries (see getProductsPage). */
  variants?: number;
  images?: number;
}

export type ListRequest =
  | ({ scope: "collection"; handle: string } & ListOptions)
  | ({ scope: "all" } & ListOptions)
  | ({ scope: "search"; query: string } & ListOptions);

type Sort<K> = { sortKey: K; reverse: boolean };

const COLLECTION: Partial<Record<SortChoice, Sort<CollectionSortKey>>> = {
  featured: { sortKey: "COLLECTION_DEFAULT", reverse: false },
  "best-selling": { sortKey: "BEST_SELLING", reverse: false },
  newest: { sortKey: "CREATED", reverse: true },
  "price-asc": { sortKey: "PRICE", reverse: false },
  "price-desc": { sortKey: "PRICE", reverse: true },
  "title-asc": { sortKey: "TITLE", reverse: false },
  "title-desc": { sortKey: "TITLE", reverse: true },
};

const ALL: Partial<Record<SortChoice, Sort<ProductSortKey>>> = {
  featured: { sortKey: "RELEVANCE", reverse: false },
  "best-selling": { sortKey: "BEST_SELLING", reverse: false },
  newest: { sortKey: "CREATED_AT", reverse: true },
  "price-asc": { sortKey: "PRICE", reverse: false },
  "price-desc": { sortKey: "PRICE", reverse: true },
  "title-asc": { sortKey: "TITLE", reverse: false },
  "title-desc": { sortKey: "TITLE", reverse: true },
};

const SEARCH: Partial<Record<SortChoice, Sort<SearchSortKey>>> = {
  relevance: { sortKey: "RELEVANCE", reverse: false },
  "price-asc": { sortKey: "PRICE", reverse: false },
  "price-desc": { sortKey: "PRICE", reverse: true },
};

const TABLES = { collection: COLLECTION, all: ALL, search: SEARCH } as const;

export function sortFor(scope: "collection", choice?: string | null): Sort<CollectionSortKey> | null;
export function sortFor(scope: "all", choice?: string | null): Sort<ProductSortKey> | null;
export function sortFor(scope: "search", choice?: string | null): Sort<SearchSortKey> | null;
export function sortFor(scope: ListScope, choice?: string | null): Sort<string> | null {
  const table = TABLES[scope] as Record<string, Sort<string> | undefined>;
  // hasOwnProperty, so "toString" or "constructor" from a URL is not a sort.
  return choice && Object.prototype.hasOwnProperty.call(table, choice) ? (table[choice] ?? null) : null;
}

/** The sort choices a read can do, for the sort dropdown. The labels are the design's own words. */
export function sortChoices(scope: ListScope): SortChoice[] {
  return Object.keys(TABLES[scope]) as SortChoice[];
}

export type SearchParamsLike = URLSearchParams | Record<string, string | string[] | undefined>;

const FILTER = "filter";
const PRICE_MIN = "price.min";
const PRICE_MAX = "price.max";
// The ProductFilter fields Shopify takes back. Anything else in the URL was typed by hand.
const FILTER_KEYS = new Set(["available", "category", "productMetafield", "productType", "productVendor", "tag", "taxonomyMetafield", "variantMetafield", "variantOption"]);

const allOf = (params: SearchParamsLike, key: string): string[] =>
  params instanceof URLSearchParams ? params.getAll(key) : [params[key] ?? []].flat();

function price(params: SearchParamsLike, key: string): number | undefined {
  const raw = allOf(params, key)[0];
  if (raw === undefined || raw.trim() === "") return undefined;
  const n = Number(raw);
  return Number.isFinite(n) && n >= 0 ? n : undefined;
}

/**
 * The filters a shopper picked, from the URL. A filter box is `<input type="checkbox" name="filter" value={value.input}>`,
 * a price range is two boxes named `price.min` and `price.max`, so a plain GET form fills the URL with no script.
 */
export function filtersFromSearchParams(params: SearchParamsLike): ProductFilterInput[] {
  const filters: ProductFilterInput[] = [];
  for (const raw of allOf(params, FILTER)) {
    try {
      const input: unknown = JSON.parse(raw);
      if (!input || typeof input !== "object" || Array.isArray(input)) continue;
      const keys = Object.keys(input);
      if (keys.length === 1 && FILTER_KEYS.has(keys[0])) filters.push(input as ProductFilterInput);
    } catch {
      // Not JSON: a hand-edited URL. Drop it.
    }
  }
  const min = price(params, PRICE_MIN);
  const max = price(params, PRICE_MAX);
  if (min !== undefined || max !== undefined) filters.push({ price: { ...(min !== undefined ? { min } : {}), ...(max !== undefined ? { max } : {}) } });
  return filters;
}

/** The URL parameters for these filters, keeping everything else in `base` (sort, q). */
export function filtersToSearchParams(filters: ProductFilterInput[], base?: URLSearchParams | string): URLSearchParams {
  const params = new URLSearchParams(base);
  for (const key of [FILTER, PRICE_MIN, PRICE_MAX]) params.delete(key);
  for (const f of filters) {
    if (f.price) {
      if (f.price.min !== undefined) params.set(PRICE_MIN, String(f.price.min));
      if (f.price.max !== undefined) params.set(PRICE_MAX, String(f.price.max));
    } else params.append(FILTER, JSON.stringify(f));
  }
  return params;
}

const canonical = (value: unknown): string =>
  JSON.stringify(value, (_key, v) =>
    v && typeof v === "object" && !Array.isArray(v) ? Object.fromEntries(Object.entries(v).sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0))) : v
  );

/** Whether a filter value (from page.filters) is among the picked filters: ticks its box. */
export function isFilterPicked(filters: ProductFilterInput[], value: { input: string }): boolean {
  try {
    const want = canonical(JSON.parse(value.input));
    return filters.some((f) => canonical(f) === want);
  } catch {
    return false;
  }
}

/** The lowest and highest price Shopify offers in a PRICE_RANGE filter: the price boxes' placeholders. */
export function priceRange(filter: Filter): { min: number; max: number } | null {
  if (filter.type !== "PRICE_RANGE") return null;
  try {
    const p = JSON.parse(filter.values[0]?.input ?? "").price;
    return typeof p?.min === "number" && typeof p?.max === "number" ? { min: p.min, max: p.max } : null;
  } catch {
    return null;
  }
}

export async function getAllProductsPage(options: GetAllProductsOptions = {}): Promise<ProductPage> {
  const { sort, filters, allHandle = "all", ...rest } = options;

 * each other share an untitled column. Do not use the menu's own title ("Footer") as a heading.
 * Also returns the shop's policies the menu does not link yet, so none is listed twice.
 */
export function footerColumns(links: MenuLink[], policies: Pick<ShopPolicy, "title" | "handle">[] = []): { columns: FooterColumn[]; policies: MenuLink[] } {
  const columns: FooterColumn[] = [];
  for (const link of links) {
    if (link.items.length) columns.push({ title: link.title, links: link.items });
    else if (columns.at(-1)?.title === null) columns.at(-1)!.links.push(link);
    else columns.push({ title: null, links: [link] });
  }
  const linked = new Set(allHrefs(links));
  return {
    columns,
    policies: policies
      .map((p) => ({ title: p.title, href: `/policies/${p.handle}`, external: false, items: [] }))
      .filter((p) => !linked.has(p.href)),
  };
}
